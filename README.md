## Featured project: Lucy

> **One platform // Any robot**

Lucy is an open-source robotics framework. Its core runs all the ROS 2 logic and installs in a few commands on macOS, Windows or Linux, without Docker. Robots plug in on one side, control interfaces on the other.

| Interfaces | | Lucy core | | Robots |
| :--- | :---: | :--- | :---: | :--- |
| Lucy Control Panel · CLI · HuRI (AI) · your own | → | ROS 2 · `ros2_control` · `lucy_ws` · embedded firmware | → | InMoov · SO-101 arm · yours |

[Website](https://lucy-robotics.com/) · [Documentation](https://docs.lucy-robotics.com/share/p1x9ikjkhf/p/public-documentation-EExgMX2REV) · [GitHub](https://github.com/Lucy-Robotics) · [Roadmap](https://projects.sentience-robotics.fr/) · [Discord](https://discord.gg/g4KNZ3eeBd)
